# Énoncés de TP et d'examens (résumés)

Résumés **personnels et anonymisés** des énoncés du dossier de cours : objectif, données, règles, résultat attendu, compétences, et **où trouver des solutions dans ce dépôt**. Les énoncés originaux restent hors dépôt (droits du centre de formation) ; aucun nom de personne, d'organisme, d'adresse ou de machine n'est repris. Le champ `id` sert aussi d'identifiant d'exercice dans [`contributions/`](../../contributions/README.md) : mêmes `id` = mêmes consignes, donc variantes comparables ([VARIANTES](../VARIANTES.md)).

> **Règle des épreuves** : le TP surprise et l'examen interdisent l'aide d'une IA (et limitent la documentation autorisée) **pendant l'épreuve**. Ces pages servent à la **révision** après coup, pas à passer une épreuve en cours.
