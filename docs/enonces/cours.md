# Cours du dossier (sommaires)

Les supports eux-mêmes restent hors dépôt. Ce tableau indique ce que chacun couvre et ce qui a pu être lu.

| Support | Contenu | État de lecture |
|---|---|---|
| **RPG/400 (RPG III)**, 125 diapositives | histoire du RPG (I, II, III, RPG/400, « GAP » en France) ; PDM/SEU ; spécifications **H, F, E, L, I, C, O** ; `SETON LR`, `DSPLY`, `MOVE`/`MOVEL` ; indicateurs ; `IF`/`SELEC`/`WHEN` ; boucles `DOW`/`DO`/`GOTO` ; `AND`/`OR` ; arithmétique (`ADD`, `SUB`, `MULT`, `DIV`, `MVR`, `Z-ADD`) ; `COMP` ; accès base (`SETLL`, `SETGT`, `READ`/`READE`/`READP`/`READC`, `CHAIN`, `WRITE`, `UPDAT`, `DELET`, `KLIST`) ; `EXSR`/`CASxx` ; `PLIST` et appel externe ; `EXFMT` ; tableaux (`MOVEA`) ; **TP 1 à 4** (Hello World, prix TTC, passage de paramètres, gestion des livres, gestion des commandes avec `EXSR`) | texte complet lu |
| **DB2 for i** (≈ 80 pages) | modèle relationnel (Codd, System R, DB2), clés, intégrité, manipulation par l'éditeur écran vert | début lu ; reste non analysé |
| **Développement web** (outil de conception d'écrans web pour IBM i, ≈ 35 pages) | écran fiche (boutons, civilité, date de naissance, contrôle du nom, onglets), écran sous-fichier (colonnes variables, pagination, appel de fiche, envoi de mail, glisser-déposer) | plan lu |
| **RPG full free** (≈ 110 pages) et **sous-fichier SFL** (≈ 50 pages) | cours en images : le texte n'est pas extractible | **non lus** |
| Diaporama d'équipe pour [tp-the-big-one](tp-the-big-one.md) | répartition des rôles, atelier commun, bugs, modernisation | lu (résumé dans la page du TP) |

Constats : le cours RPG III couvre `CASxx`, `KLIST`, `READP` qui sont **utilisés dans le code mais absents des fiches** ; les fiches 03 et 06 n'en parlent pas ([MANQUES](../MANQUES.md)).
